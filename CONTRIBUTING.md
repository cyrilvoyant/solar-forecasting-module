# Contributing

Thank you for using this module. Every remark helps other students and instructors.

## Report a problem or ask a question

Open an issue on GitHub. Please say:

- which session and which page or code;
- what you did, what you expected, what you got (a screenshot helps);
- your browser, or your MATLAB/Python version.

You can also write to cyril.voyant@minesparis.psl.eu.

## Suggest a change

- Small fixes (a typo, a broken link, a clearer question): open a pull request on this repository.
- Changes to an interactive page or a code: open an issue first. The pages and codes live in their own repositories (see the submodules); they are pinned here to a fixed version so that every number of the module stays reproducible.

## Share your experience

If you teach with this module, tell us how (level, duration, what you changed) in an issue. It helps improve the sequence.

## Code of conduct

Be kind and precise. Criticise ideas, not people.
